Changelog

All notable changes to Dani Music are documented here.

[1.0.0] - 2026-11-26

Initial release

- Initial Android application release.
- Local audio playback.
- Video playback.
- Background playback service.
- Media playback notifications.
- Favorites and playlist-related components.
- Integrated Dani assistant.
- Floating assistant bubble.
- Lyrics functionality with optional online lookup.
- Theme and accent customization.
- Aurora and Premium visual components.
- Android Picture-in-Picture support for video.

Technical

- Kotlin.
- Jetpack Compose.
- Material 3.
- Minimum Android SDK 23.
- Target Android SDK 36.
